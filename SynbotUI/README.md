# SynbotUI

This folder contains the standalone frontend React application for RoyanHealth — Royan Hospital.

## Notes
- This is not packaged as a WordPress admin plugin UI.
- WordPress integration is handled separately by the lightweight floating chat widget plugin in `placeware-chat-widget/`.
- Backend API is hosted separately and consumed by this UI.

## Run (from this folder)
- `pnpm install`
- `pnpm dev`
